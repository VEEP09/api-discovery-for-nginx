# UI 문자열 카탈로그 (작업 중)

`data-i18n` / `data-i18n-attr` 속성으로 참조되는 UI 문자열의 언어별 카탈로그입니다.

## 현재 상태

**언어 전환 기능은 아직 활성화되지 않았습니다.** UI 기본 언어는 영어이며,
HTML 에 영어 원문이 그대로 들어 있어 카탈로그 없이도 정상 동작합니다.

여기 담긴 키는 과거 한국어로 작성되어 있던 문자열 64건뿐입니다. `index.html`
에는 처음부터 영어로 작성된 문자열이 약 114건 더 있고 여기에는 아직 키가
없습니다. 이 상태로 한국어 전환을 켜면 화면 절반이 영어로 남아 혼재되므로,
전환 UI 를 노출하지 않고 있습니다.

## 다음 단계

1. `index.html` 의 키 없는 영어 문자열에 `data-i18n` 부여
2. `dashboard.js` 의 문자열 리터럴을 `t('key')` 로 치환
3. `static/i18n.js` 로드 + 언어 선택 UI 노출

## 규칙

- 키는 `영역.대상[.속성]` 형태의 dot notation (`spec.dropzone`, `stat.calls.tip`)
- 모든 언어 파일은 **동일한 키 집합**을 가져야 한다. `tests/test_i18n_catalog.py` 가 검증한다.
- 서버는 언어를 알지 못한다. 사용자 노출 메시지는 영어 고정이며, 다국어화할 경우
  번역문 대신 안정적인 에러 코드를 반환하고 프론트에서 렌더링한다.
