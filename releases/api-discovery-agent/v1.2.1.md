## What changed

Nothing in the agent itself — the image is bit-for-bit the `1.2.0` image. Collection behaviour, log output, the cursor format, `--help`, and every environment variable are identical to `1.2.0`. Image size stays at 21 MB compressed.

## Why the version bump

The dashboard and the agent ship as a matched pair on the same version tag, and running mismatched tags is not a configuration this project tests. [`api-discovery-nginx` 1.2.1](../api-discovery-nginx/v1.2.1.md) fixes defects in the dashboard's language switcher, so the agent moves with it.

If you are on `1.2.0` and only want the dashboard fixes, pulling the dashboard alone works — but pinning both to `1.2.1` keeps the pair aligned.

## Upgrading

No configuration changes:

```bash
docker pull gusgh13900/api-discovery-agent:1.2.1
```

Your cursor file (`CURSOR_FILE`) is preserved across restarts, so no log lines are re-sent or skipped. `1.2.0` remains on Docker Hub if you need to roll back.
