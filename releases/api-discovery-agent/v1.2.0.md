## What changed

16 strings, all of them things you actually see:

- **Log messages** — collection, delivery, log rotation, connection errors
- **Startup banner** — `Agent started - dashboard=…, poll=30s`
- **Configuration errors** — the messages raised when `DASHBOARD_URL` or `LOG_PATH` is missing
- **`--help` output** — the `--config` and `--once` descriptions

Logs are deliberately **not** translated per-language, unlike the dashboard interface. When you paste an error into an issue, it has to be searchable; a message that varies by locale is not.

Collection behaviour, the cursor format, and every environment variable are unchanged. Image size stays at 21 MB compressed.

## Why the version bump

The dashboard and the agent ship as a matched pair on the same version tag. [`api-discovery-nginx` 1.2.0](../api-discovery-nginx/v1.2.0.md) is a substantial release, so the agent moves alongside it.

## Upgrading

No configuration changes:

```bash
docker pull gusgh13900/api-discovery-agent:1.2.0
```

Your cursor file (`CURSOR_FILE`) is preserved across restarts, so no log lines are re-sent or skipped. `1.1.0` remains on Docker Hub if you need to roll back.
