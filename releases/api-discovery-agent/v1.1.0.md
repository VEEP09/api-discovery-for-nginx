# api-discovery-agent 1.1.0

**2026-08-11** · [Docker Hub](https://hub.docker.com/r/gusgh13900/api-discovery-agent)

A maintenance release. **No source changes** — `agent.py`, its dependencies, and the Dockerfile are identical to `1.0.0`.

```
docker pull gusgh13900/api-discovery-agent:1.1.0
```

## What changed

The `gcr.io/distroless/python3-debian12` base image was refreshed upstream, so the agent was rebuilt to pick up those security patches.

Image size is unchanged at **21 MB** compressed.

## Why the version bump

The dashboard and the agent are documented as a matched pair — same version tag on both sides. Since [`api-discovery-nginx` 1.1.0](../api-discovery-nginx/v1.1.0.md) shipped a significant packaging change, the agent moves to `1.1.0` alongside it so that pairing still holds.

## Upgrading

No configuration changes. Pull and restart:

```bash
docker pull gusgh13900/api-discovery-agent:1.1.0
```

Your cursor file (`CURSOR_FILE`, default `/agent/state/agent_cursor.json`) is preserved across restarts, so no log lines are re-sent or skipped.

Behaviour is identical to `1.0.0`. `1.0.0` remains on Docker Hub if you need to roll back.

## Verified

- NGINX access-log collection working
- NGINX Plus metrics collection working
