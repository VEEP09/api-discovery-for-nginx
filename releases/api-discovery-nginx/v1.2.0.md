# api-discovery-nginx 1.2.0

**2026-08-12** · [Docker Hub](https://hub.docker.com/r/gusgh13900/api-discovery-nginx)

The dashboard is now **in English**, with a built-in **English / Korean** switcher. No behavioural, configuration, or API changes.

```
docker pull gusgh13900/api-discovery-nginx:1.2.0
```

`sha256:ae2ed3b69d1a713d665c34b6418991cd5540de06297f8e82b0f05eae90273cda`

---

## Why

`1.1.0` brought the Docker Hub pages and this repository into English — but the thing you actually run did not follow. Every label, tooltip, and error message in the dashboard was Korean-only, so anyone who pulled the image landed on a screen they could not read.

## What changed

### The interface is in English

Everything the dashboard renders — tabs, stat cards, table headers, filters, tooltips, empty states, error messages — is now English by default.

| Area | Strings |
|------|---------|
| `index.html` | 34 attributes + 30 text nodes translated, then 72 texts + 14 attributes keyed |
| `login.html` | all |
| `dashboard.js` | 78 UI strings |
| `app.py` | 26 user-facing messages (`detail` / `error` / `message`) |

### Language switcher

A selector sits in the top bar and on the login page. Two languages ship today: **English** and **Korean**.

Your choice is remembered in `localStorage`. On a first visit with nothing stored, the dashboard follows your browser's language and falls back to English. The login page is served before you authenticate, so the preference deliberately lives in the browser rather than on your account.

Translations are plain JSON catalogs under `/static/i18n/`. The English text is written directly into the HTML, so the page renders correctly even if a catalog fails to load, and English users see no flash of substituted text.

### Logs are English too

70 log lines across the dashboard and the agent, including the agent's startup banner, configuration errors, and `--help` output.

Logs are deliberately **not** translated per-language. When you paste an error message into an issue, it has to be searchable — a message that varies by locale is not.

## Upgrading

No configuration changes. Pull and restart:

```bash
docker pull gusgh13900/api-discovery-nginx:1.2.0
docker pull gusgh13900/api-discovery-agent:1.2.0
```

- Your `/app/output` volume is fully compatible — database, trained models, and accounts carry over.
- Korean users see no regression: if the browser reports Korean, the dashboard starts in Korean.
- `1.1.0` remains on Docker Hub if you need to roll back.

## Verified

- Full test suite: 50 passing, including 6 catalog-integrity tests
- English rendering confirmed on the login page, dashboard body, and API error responses
- Korean switch confirmed: 106 text nodes and 49 attributes substituted
- End-to-end ingestion from agent to dashboard after redeploy

## Known issue

The dashboard still creates a default `admin` / `admin1234` account on first start. **Change the password immediately after deploying.** A future release will generate a random password and print it to the container log instead.
